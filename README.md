# 📡 Cisco Packet Tracer Labs - CCST Networking Basics
## 📖 Descripción
Repositorio con prácticas y actividadedes de **`Cisco Packet Tracer`**, dedicado a la documentación de progreso en conceptos fundamentales de **Networking** (Seguridad y Funcionamiento de Redes)
## 🎯 Objetivo 
- Desarrollar habilidades en configuración y simulación de redes
- Preparar la certificación CCST Cybersecurity de CISCO
- Documentar conceptos clave de networking
- Aportar a la comunidad y a los futuros estudiantes
## 📋 Requisitos
- **Cisco Packet Tracer** (versión 8.0+)
- Conocimientos básicos de networking
- Windows, MacOS o Linux
## 🚀 Cómo usar el repositorio
1. Clonar el repositorio
```bash
git clone https://github.com/slbz-ccst/packet-tracer-labs.git
```
2. Abrir archivos **`.pkt`** en Packet Tracer
3. Leer el **README.md** de cada actividad para más detalles
4. **Recomendado:** Acceder a "Learning Collection" de Cisco Packet Tracer en Cisco Networking Academy
